  PASSO A PASSO
═══════════════════════════════════════════════════════

1. HOSTINGER — Após comprar o plano Business:
   • hPanel → Bases de dados → Criar base de dados MySQL
   • Anota: nome da BD, utilizador e password

2. config.php — Preenche com os teus dados:
   • DB_NAME, DB_USER, DB_PASS (da base de dados)
   • STRIPE_SECRET_KEY (em dashboard.stripe.com → Developers → API keys)
   • STRIPE_WEBHOOK_SECRET (após criar o webhook no Stripe)
   • MAIL_FROM (o teu email profissional)
   • SITE_URL (https://andreiarodrigues.com)
   • Os IDs dos produtos Stripe (após criar os produtos)

3. CARREGAR FICHEIROS:
   • Todos os ficheiros HTML → public_html/
   • A pasta /acesso/ com os ficheiros PHP → public_html/acesso/

4. INSTALAR A BASE DE DADOS:
   • Visita https://andreiarodrigues.com/acesso/instalar.php
   • Deverás ver: "Base de dados instalada com sucesso!"
   • APAGA imediatamente o ficheiro instalar.php do servidor

5. STRIPE — Configurar Webhook:
   • dashboard.stripe.com → Developers → Webhooks → Add endpoint
   • URL: https://andreiarodrigues.com/acesso/webhook.php
   • Events: checkout.session.completed
   • Copia o "Signing secret" → coloca em STRIPE_WEBHOOK_SECRET no config.php

6. STRIPE — Criar Payment Links:
   • Cria um produto para cada item (Révélation™, Academia, Coffret™, Collection™)
   • Gera um Payment Link para cada um
   • Substitui os links href="#" nas páginas de venda

7. TESTAR:
   • Vai a https://andreiarodrigues.com/acesso/login.php
   • Deves ver a página de login da Maison Isabella
